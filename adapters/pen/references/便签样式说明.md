## 样式参数说明

### fontSize (字体大小)

- **12px**: 小号，适用于次要信息、备注、待办事项
- **13px**: 中号，适用于字段说明、交互说明
- **14px**: 大号，适用于主要功能说明、重要内容

### lineHeight (行高)

- **1.5**: 标准行高，适用于大多数场景
- **1.6**: 宽松行高，适用于需要更多呼吸感的文本

### width (宽度)

- **250-270px**: 窄宽度，适用于简洁的内容
- **290-310px**: 中等宽度，平衡可读性和空间占用
- **340px**: 宽宽度，适用于详细说明和长文本

## 创建便签的完整示例

### 方式 1: 使用 Frame 包裹（推荐，支持背景色）

```javascript
// 创建带颜色背景的便签容器
noteFrame=I(document,{
  type:"frame",
  x:100,
  y:100,
  width:370,
  height:220,
  fill:"#E3F2FD",        // 浅蓝背景
  cornerRadius:8,        // 圆角
  padding:16,            // 内边距
  layout:"vertical"      // 垂直布局
})

// 添加标题
noteTitle=I(noteFrame,{
  type:"text",
  content:"📝 功能说明",
  fontSize:16,
  fontWeight:"bold",
  fill:"#1976D2"         // 深蓝标题
})

// 添加便签内容
note=I(noteFrame,{
  type:"note",
  content:"本页面用于...",
  width:340,
  fontSize:14,
  lineHeight:1.6
})
```

### 方式 2: 纯 Note 节点（无背景色）

```javascript
// 直接创建便签（无背景色）
note=I(document,{
  type:"note",
  name:"功能说明",
  content:"本页面用于展示用户管理功能...",
  x:100,
  y:100,
  width:350,
  fontSize:14,
  lineHeight:1.6
})
```

## 重要提示

1. **背景色实现**: Note 节点本身不支持 fill 属性，需使用 Frame 包裹实现背景色
2. **自动高度**: 便签的高度会根据内容自动计算，无需手动设置 height
3. **文本换行**: 使用 `\n` 在内容中进行换行
4. **推荐布局**: 在页面设计时，将便签放置在画布边缘或空白区域，避免遮挡主要内容
5. **颜色语义**: 不同类型的便签使用不同颜色，便于快速识别

---

## 后续使用建议

1. **颜色一致性**: 在项目中保持每种类型便签的颜色一致
2. **位置规范**: 建议将便签放在画布右侧或底部，距离主要内容至少 50px
3. **命名规范**: 使用清晰的中文名称，如 "功能说明"、"字段说明"
4. **内容精简**: 保持便签内容简洁明了，避免过多细节
5. **定期维护**: 随着项目进展，及时更新便签内容
