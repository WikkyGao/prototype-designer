# 微光清单 — 设计规范

> 设计方法来自 `design-master`：先定视觉方向与心理目标，再落到令牌、组件状态与无障碍。
> 本文件只定义规则；具体值见 `tokens.json` 与 `variables.css`。

## 1. 视觉方向

**关键词**：温润、克制、纸感、专注、可长时间阅读。

- 主风格：极简主义 + 轻编辑感
- 情绪目标：打开时「安静」，操作后「有回音」
- 避免：高饱和渐变、玻璃拟态、密集阴影、装饰性插画
- 视觉记忆点：宋体标题 + 等宽小标签 + 黄铜色细分隔线

### 两套外壳

| 外壳 | 用途 | 视觉职责 |
|---|---|---|
| editorial-ink | 直出评审主版本 | 顶部页面切换、居中舞台、页面级备注 |
| project | 标注评审版本 | 左导航、中预览、右说明；水滴标注 + 贝塞尔连线 |

页面内容、字段与交互在两套外壳中完全一致。

## 2. 网格与空间

- 内容最大宽度：1120px；正文阅读宽度不超过 64ch
- 基础间距：4 / 8 / 12 / 16 / 24 / 32 / 48
- 页面留白：桌面 28–40px，移动 18–22px
- 圆角：小 7px、中 10px、大 14px
- 分隔优先用 1px 发丝线，不用重阴影

## 3. 字体

- 标题：Songti SC / Source Han Serif SC / Georgia
- 正文：PingFang SC / HarmonyOS Sans SC / system-ui
- 标签与数字：JetBrains Mono / SFMono-Regular / Consolas

字号阶梯：

| 角色 | 字号 | 行高 |
|---|---|---|
| 页面主标题 | 26–30px | 1.25 |
| 区块标题 | 18–20px | 1.35 |
| 正文 | 13–14px | 1.7 |
| 辅助信息 | 11–12px | 1.6 |
| 等宽标签 | 9.5–10.5px | 1.4 |

## 4. 色彩

| 角色 | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| 背景 | `#F4F1E8` | `#0B0C0E` | 页面底色 |
| 表面 | `#FCFAF4` | `#111317` | 卡片、面板 |
| 主文字 | `#1E1D1A` | `#E9E6DD` | 标题、正文 |
| 次文字 | `#5F5C54` | `#9C9A92` | 说明、元信息 |
| 强调 | `#2F4F77` | `#3F6491` | 主按钮、当前项 |
| 标记 | `#8A6420` | `#C89B52` | 备注线、重点提示 |
| 成功 | `#3F6B4E` | `#5FA37A` | 完成态 |
| 危险 | `#963B32` | `#C96358` | 删除、错误 |

对比度：正文与背景 ≥ 4.5:1；大字号 ≥ 3:1；焦点环可见。

## 5. 组件规则

### 按钮

- 主按钮：实色强调底 + 米白文字；hover 提亮，active 下沉 1px
- 次按钮：透明底 + 发丝边框；hover 边框加强
- 危险按钮：仅在确认弹层内使用实色
- 所有按钮最小点击区 40×40（移动端 44×44）

### 任务行

- 结构：复选框 / 标题与元信息 / 优先级 / 删除
- 完成态：标题降权 + 删除线；复选框填色；行背景轻微变化
- hover：行背景抬升一档；不改变布局
- 删除按钮默认低对比，hover/聚焦时变为危险色

### 备注卡（project）

- 结构：编号 / 类型 / 页面 / 标题 / 正文 / 定位
- 类型色只用于左侧 3px 竖线、类型胶囊与编号，不铺满整卡
- 当前选中：2px 外环 + 连线加粗
- 正文最多 4 行，超出省略；完整内容可展开

### 水滴标记

- 真实泪滴形状，上圆下尖，尖端即锚点
- 渐变蓝 + 白色高光 + 细描边
- 数字居中；hover 显示标签；拖拽时暂停脉冲
- 选中时放大 1.06，并出现柔光环

## 6. 动效

- 标准时长：180–240ms
- 缓动：`cubic-bezier(.16, 1, .3, 1)`
- 页面进入：淡入 + 上移 8px
- 任务完成：复选框缩放 + 标题删除线逐步出现
- 连线：虚线缓慢流动；选中时改为实线
- `prefers-reduced-motion: reduce` 时关闭所有非必要动画

## 7. 无障碍

- 语义化标签：`nav` / `main` / `section` / `button` / `form`
- 图标按钮必须有 `aria-label`
- 弹层：`role="dialog"` + `aria-modal="true"` + 焦点回收
- 表单错误用 `role="alert"`，并与输入框 `aria-describedby` 关联
- 颜色不是唯一信息载体：优先级同时有文字
- 键盘：Esc 关闭弹层；Tab 顺序与视觉顺序一致
