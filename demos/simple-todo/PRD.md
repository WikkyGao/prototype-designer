# PRD — 微光清单（演示需求）

> 这是一个用于验证 `prototype-designer` 直出 HTML 原型能力的简单需求，不是完整商业产品。
> 目标：用同一个需求，对比「纸墨编辑风 editorial-ink」与「三栏水滴标注 project」两种产出。

## 1. 产品概述

**微光清单**是一款只服务「今天」的个人待办工具。它不要求用户建立复杂项目，只回答三个问题：

1. 今天还剩什么没做？
2. 哪些已经完成？
3. 昨天/更早完成的事去哪了？

## 2. 目标用户

- 每天有 3–8 件零散事务的个人用户
- 不想学习 GTD、看板、标签体系，只想快速记下并划掉
- 使用场景：早晨通勤列清单、工作中随手勾选、睡前回看完成情况

## 3. 页面与路由

| 页面 | 路由 | 目标 |
|---|---|---|
| 登录 | `/login` | 用邮箱/密码进入，或使用演示账号 |
| 今日清单 | `/today` | 查看今日任务、新建、勾选、筛选、删除 |
| 归档 | `/archive` | 回看已完成任务，支持恢复到今日 |

## 4. 功能需求

### 4.1 登录

- 邮箱、密码必填；邮箱需包含 `@`
- 提交后按钮进入 loading，约 0.7s 后进入今日清单
- 提供「使用演示账号」：自动填入演示邮箱与密码，不直接登录
- 表单错误时在表单上方显示可读错误，并保留已填内容

### 4.2 今日清单

- 顶部展示日期、问候语与完成进度
- 统计区展示：完成数、专注时长、连续天数
- 筛选：全部 / 进行中 / 已完成；筛选不改变统计数据
- 任务行展示：完成态、标题、标签、时间、优先级
- 点击复选框切换完成状态，进度与筛选结果即时更新
- 点击任务标题打开右侧详情抽屉（演示：标题、标签、优先级、创建时间）
- 删除任务前必须二次确认
- 「新建任务」打开模态框；标题必填，标签与优先级可选；提交后插入列表顶部并 Toast 提示
- 所有数据保存在 `localStorage`，刷新后仍在

### 4.3 归档

- 按完成日期分组展示
- 每条归档展示标题、标签、完成时间
- 「恢复到今日」将任务移回今日清单（未完成状态）
- 无归档数据时展示空状态，不出现空白列表

## 5. 交互与状态

| 状态 | 处理 |
|---|---|
| 空列表 | 显示空状态 + 「新建第一件事」按钮 |
| 加载 | 登录按钮 loading；列表不整页闪烁 |
| 错误 | 登录表单内联错误；删除失败 Toast |
| 成功 | 新建/恢复/删除均有 Toast |
| 键盘 | 所有按钮可 Tab 聚焦，Enter/Space 触发；Esc 关闭弹层 |
| 减少动效 | 尊重 `prefers-reduced-motion` |

## 6. 数据字段（演示）

任务：`id`、`title`、`tag`、`priority`（high/medium/low）、`done`、`date`（today/archive）、`time`、`completedAt`。

## 7. 非目标

- 不做注册、找回密码、真实鉴权
- 不做多端同步、团队协作、提醒推送
- 不做复杂项目管理（项目、子任务、依赖）

## 8. 验收标准

1. 三个页面可切换，路由标识正确
2. 登录、新建、勾选、筛选、删除、恢复均可操作
3. 刷新后任务状态保留
4. 桌面 1440px 与移动 390px 下无横向滚动
5. editorial-ink 具备顶部页面切换与「看全部备注」
6. project 版本具备三栏、水滴标注、说明面板与可用连线
