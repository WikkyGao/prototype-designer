# 登录页设计规范（演示默认值）

> 默认值待确认：本文件为 Axure CLI 验证用的最小规范，未继承任何真实项目设计系统。
> 原生 `.rp` 使用 zee-rp 内置 `enterprise-light` 主题；下列 token 已与该主题对齐。

## 画布

- 桌面端 1440 × 900
- 左右分栏：左侧品牌区 880，右侧表单区 560
- 表单宽 360，在右侧区域垂直水平居中
- 表单元素间距 14

## 颜色

| 令牌 | 值 | 用途 |
|---|---|---|
| `$bg` | `#F4F6F9` | 页面背景 |
| `$surface` | `#FFFFFF` | 卡片背景 |
| `$line` | `#E2E8F0` | 卡片/输入框描边 |
| `$ink` | `#1E293B` | 主文字 / 左侧品牌区背景 |
| `$ink-2` | `#475569` | 次要文字 |
| `$brand` | `#FF8833` | 主按钮 |
| `$danger` | `#EF4444` | 校验提示（本页暂用中性色，避免成功态显红） |

## 字体

- 中文：`PingFang SC`
- 英文与数字：`Inter`
- 标题 24 / 700，正文 13 / 400，标签 13 / 600，按钮 14 / 600

## 控件规则

- 输入框高 40，圆角 8，描边 1px `$line`
- 主按钮高 40，圆角 8，使用 `$brand`
- 校验提示固定在按钮下方，避免布局跳动
- 左侧品牌区使用 `$ink` 深色底，文字用 `$surface` 反白

## 复用说明

- 未提供标准控件库：本页使用 zee-rp 原生 TextBox / Button 默认实现，属于「默认值待确认」。
- 后续接入项目控件库时，优先替换输入框与按钮，不改变交互结构。
