# 登录页 · 简单验证需求

> 用途：验证 prototype-designer Axure 适配器的 CLI 模式。所有设计值均为演示默认值，正式项目需替换为项目规范。

## 1. 目标

为内部管理后台提供一个可继续在 Axure RP 中编辑的登录页原型。

## 2. 页面与字段

| 页面 | 元素 | 说明 |
|---|---|---|
| 登录页 | 标题 | 欢迎登录 |
| 登录页 | 副标题 | 请使用企业账号登录 |
| 登录页 | 账号输入框 | 占位提示「请输入手机号或邮箱」，必填 |
| 登录页 | 密码输入框 | 占位提示「请输入密码」，必填 |
| 登录页 | 登录按钮 | 点击后校验并给出结果提示 |
| 登录页 | 结果提示 | 空账号 / 空密码 / 登录成功三种状态 |

## 3. 交互规则

1. 账号为空 → 提示「请输入账号」。
2. 账号非空但密码为空 → 提示「请输入密码」。
3. 账号、密码均非空 → 提示「登录成功（示例）」。

## 4. 范围外

- 不接真实登录接口
- 不做注册、找回密码
- 不做响应式与多语言

## 5. 产出

- 原生 `.rp`（Axure RP 9，CLI 生成）
- 结构校验证据（三零 + version-lint）
- 默认不接管 GUI，原生预览标记为待验收
