💧 一、水滴标注点样式
标注点用于在主页面中标记交互型控件（按钮、输入框等），点击可连线到右侧说明面板对应的说明卡片。

1.1 标注点形状 — SVG 真实水滴

A. 经典泪滴（上圆下尖）
顶部饱满圆润 + 底部锥形收尖，顶部 3 层渐变 + 白光反射
B. 修长水滴
更高挑纤细，底部尖角延长，比例优雅
C. 玻璃水滴（半透+弧光）
半透明填充 + 描边 + 弧形反光条，真实水珠质感
D. 圆润大水滴（斜向渐变+投影）
宽大饱满的顶部 + 细短尖尾，drop-shadow 立体感
E. 扁平露珠（宽扁）
宽>高，低矮圆顶+短锥尾，叶片露珠效果
F. 小水珠（顶白渐变）
顶部白色高光直接融入深橙底部，真实折射效果

1.2 动画效果

P1. 脉冲光晕
阴影周期性扩散收缩（2s），吸引注意力
P2. 摆动摇晃
水滴轻微左右摆动（2.5s），灵动活泼
P3. 呼吸（透明度渐隐）
透明度渐隐渐现（2.5s），柔和提示不扰人
P0. 无动画（静态）
纯静态水珠，不分散注意力

1.3 标注点色系

橙色系（默认）
温暖醒目 #ff5722，与大多数 UI 配色不冲突
蓝色系
专业冷静 #1565c0，与说明卡片标题色一致
红色系
紧急/警告感 #c62828，适合标注需要重点关注的项
↗ 二、连线样式（标注点 → 说明面板）
连线从页面中的标注点出发，指向右侧说明面板中对应的说明卡片。
L1. 贝塞尔曲线 + 虚线流动
优美弧线，虚线带流动动画，动态优雅
L2. 贝塞尔曲线 + 实线
温和弧线，半透明实线简洁不抢眼
L3. 直线虚线
简洁直接，虚线降低视觉干扰
L4. 直角折线虚线
工程蓝图风格，转角处有小圆点
L5. 贝塞尔曲线 + 圆点线
类似缝纫线效果，有趣的设计感
L6. 渐变连线（橙→蓝过渡）
从标注点橙色渐变到说明蓝色，视觉过渡自然
